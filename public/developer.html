Créer un restaurant

Avec un token qm_tok_..., votre application peut créer autant de restaurants que votre offre l'autorise.

POST /api/v1/restaurants Authorization: Bearer qm_tok_... Content-Type: application/json { "name": "Chez Marius", "slug": "chez-marius", "description": "Cuisine maison" }

cURL

curl -X POST http://localhost:3000/api/v1/restaurants ^ -H "Authorization: Bearer qm_tok_..." ^ -H "Content-Type: application/json" ^ -d "{\"name\":\"Chez Marius\"}"
